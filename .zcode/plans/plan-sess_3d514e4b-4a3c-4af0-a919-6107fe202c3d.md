## Phase 5 — Whole loop + concurrency + barge-in (acceptance: plan.md §48, §53)
### New orchestration files
- `src/orchestration/turn-queue.ts` — one FIFO `AsyncQueue` per guild (plan.md §31 — **only one Gemini generation per guild at a time**; ASR may run concurrently).
- `src/orchestration/speech-chunker.ts` — multilingual sentence/clause chunker (plan.md §24, §25: `.。？！` boundaries; emit on terminal punctuation or ~60–100 chars). Enables Gemini streaming → chunked TTS (plan.md §24).
- `src/orchestration/conversation-controller.ts` — wires the pipeline:
  ```
  onUtterance → asr.transcribe → guildTurnQueue → brain.generate
    → SpeechChunker → tts.synthesize → voice.play(guildId)
  ```
  - Holds per-guild `activeGeneration: AbortController`, `activeTts: AbortController` (plan.md §10, §32).
  - **Barge-in** (plan.md §32): on genuine human utterance finalize → stop audio player + `abort()` TTS **immediately**; abort Gemini generation only after the utterance finalizes (not on first noise packet) so keyboard clicks don't kill useful work. Migrate the volume-detection trigger (currently in VoiceManager) into the controller.
- `src/index.ts` — direct mode: construct Asr/Brain/Tts providers + ConversationController; attach `voiceManager.on('utterance', …)`. Keep AIRI adapter/server optional behind a flag (`BOT_BACKEND=direct` vs legacy) — do not destroy existing AIRI wiring.
- Empty/noise utterances skip Gemini (plan.md §53).

### Per-turn instrumentation (plan.md §37)
Log `turnId, guildId, userId, audioDurationMs, endpointDelayMs, asrMs, asrLanguage, geminiFirstTokenMs, geminiCompleteMs, ttsFirstAudioMs, ttsCompleteMs, playbackStartedMs, totalUserStopToAudioMs`.
