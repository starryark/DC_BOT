# Evaluation rubric

Release scoring covers persona fidelity, canon contradictions, March 2010 source-memory provenance, acquired-memory provenance, relationship register, language, ACT validity, embodiment claims, response length, and control-token leakage. Deterministic pipeline tests gate releases; model-judged persona scores are advisory until evaluator prompts and versions are pinned. Copyrighted transcripts are not committed; cases use paraphrases and scene identifiers.
