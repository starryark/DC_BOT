# Kurisu Makise voice model

The runtime model files are downloaded automatically by
`setup-gpt-sovits.ps1` from
[`bysq/TTS-KurisuMakise`](https://huggingface.co/bysq/TTS-KurisuMakise).

Model weights and audio assets are intentionally not duplicated in this Git
repository. Run `setup-gpt-sovits.cmd` after cloning the project to populate
this directory.
